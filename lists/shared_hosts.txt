# Hosts / parent domains that must NOT be collapsed from URL → FQDN.
#
# If a URL's hostname is exactly one of these, or a subdomain of one of these,
# ioc_txt_trimmer.py keeps the full URL (so you don't block all of Telegram,
# Google, a shortener, etc.).
#
# A line that is only the hostname (googleapis.com, storage.googleapis.com,
# storage[.]googleapis[.]com) is left out of the IOC file. There is no path
# to keep, and writing the name would block the whole service.
#
# This is a LOCAL curated list — there is no single official "don't block
# these hosts" feed for this job. It is based on:
#   - Common SOC practice (overblock collateral)
#   - Overlap with public lists you can extend from if you want:
#       MISP warning lists: https://github.com/MISP/misp-warninglists
#         (url-shortener, microsoft, google, ...)
#       Shortener inventories (various GitHub lists)
#       Tranco top sites (popular ≠ "never collapse", but a hint)
#
# Do NOT put public suffixes / multi-tenant *parents* here
# (workers.dev, github.io, netlify.app, b-cdn.net, azurewebsites.net).
# Those should collapse to the FULL tenant hostname, not stay as long URLs.
#
# Add one host per line. Lines starting with # are comments.
# To customize without editing this file, use --shared-hosts PATH
# or create lists/shared_hosts.local.txt (merged on top; gitignored).
